# Phishing Triage SOP

## Scope

Triage user-reported phishing and malicious email delivery.

## Procedure

1. Quarantine the message across mailboxes.
2. Extract URLs, attachments, and sender infrastructure.
3. Detonate attachments in sandbox; submit hashes to threat intel.
4. Reset credentials if the user interacted with the lure.
5. Update mail filters and user awareness notes.
